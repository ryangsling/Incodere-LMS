# Product

## Register

product

## Users

- **Super Admin (incodet staff)**: Platform operators managing organisations, courses, and users. Primary workflow: create orgs, build course catalogue, monitor platform health.
- **Company Admin (client HR/training manager)**: Manages their organisation's learners and enrolments. Primary workflow: invite learners, assign courses, view progress reports, download certificates.
- **Learner (employee)**: End user consuming training content. Primary workflow: watch video lessons, read text content, mark lessons complete, download certificates on completion.

## Product Purpose

ILMS is a multi-tenant Learning Management System for corporate training. It enables incodet to onboard client companies, manage course content, and let learners complete assigned training. Success is measured by learner completion rates and certificate issuance.

## Brand Personality

Professional, confident, trustworthy. The interface should feel like a premium SaaS tool used by serious companies — not playful, not clinical, but polished and assured. Three words: **refined, capable, modern**.

## Anti-references

- Generic purple-gradient-on-cream AI slop (the current state)
- Overly corporate/boring enterprise software (SAP, Workday-style)
- Playful/fun edtech (Coursera, Duolingo-style)
- Dashboard-heavy admin panels with no visual hierarchy
- Card grids with identical icon+heading+text patterns
- FAQ sections with no content

## Design Principles

1. **Substance over decoration**: Every visual element serves a purpose. No decorative gradients, no filler patterns.
2. **Confident hierarchy**: Clear visual weight. Large, bold headings. Generous whitespace. Let the typography do the talking.
3. **Consistent craft**: Every surface — landing page, dashboard, form, table — feels like it was designed by the same hand.
4. **Respect the user's time**: Fast to scan, fast to act. No unnecessary animations blocking the workflow.

## Accessibility & Inclusion

- WCAG AA compliance (4.5:1 contrast minimum)
- Reduced motion support via `prefers-reduced-motion`
- Keyboard navigable throughout
- Form inputs with proper labels and error messages
- Focus-visible states on all interactive elements
